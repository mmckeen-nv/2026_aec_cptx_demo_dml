# Project Prompt - BAC Teapot

When the user explicitly asks to build it, build the actual Utah teapot directly
in Blender from the checked-in canonical
1987 OBJ vertex/face dataset. Validate its fingerprint, topology, component
names, 0.30 m finished width, and ground contact. Never involve Rhino and never
substitute primitive or proxy geometry.

Establish a clean product stage, camera, three-point lighting, and first preview,
then pause for live audience interaction. Accept open-ended material requests
such as glazed ceramic, copper, brushed steel, chrome, glass, matte black, or a
user-selected color. Keep geometry and scale stable unless explicitly asked.

At session startup, wait. Reading this project prompt is not permission to build.
